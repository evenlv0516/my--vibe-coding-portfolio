从生成物，到可交接的交付

浏览器里能改，解决了生成与预览；但评审、归档和高频二次修改，仍发生在 PowerPoint。2.0 让编辑权回到 PPT 的使用习惯里。

HTML → PPTX 怎么转

不解析 HTML 源码，而是在真实浏览器里渲染页面，再把渲染结果翻译成可编辑的 PowerPoint 对象。

浏览器渲染→捕获 DOM→转成原生对象→写入动画并校验
01 页面内捕获

Playwright 打开幻灯片，递归序列化为 JSON 树；文本用行盒精确取位。

02 翻译为原生对象

形状、文字、图片分别映射为 PptxGenJS 对象，保留计算样式与位置。

03 动画真正可播

按 data-anim 写入原生时序；再校验翻页、尺寸与备注，输出可供 Agent 读取的结果。
